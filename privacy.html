Privacy policy

Think Tank is a personal Windows desktop app built and used by Charlie Scullion. This policy explains what Google user data the app accesses and what it does with it.

1 · Data the app accesses

When the user signs in with Google, Think Tank asks for these permissions:

  • Gmail, read (gmail.readonly): sender, recipients, subject, date, labels, snippet and, for a thread the user asks to reply to, the message text.
  • Gmail, compose (gmail.compose): used only to save reply drafts. The app has no code that sends email.
  • Calendar, read (calendar.readonly): calendars and upcoming events.
  • Calendar, events (calendar.events): used only to create an event, with a Google Meet link, when the user submits the New meeting form.
  • Basic profile (openid, email): the signed-in email address, shown in the app.

2 · How the data is used

The data is used only to show the user their own calendar and inbox, rank emails by priority, draft replies the user asks for, save those drafts to Gmail, and create meetings the user requests. It is not used for advertising or profiling, and it is never sold.

3 · Storage

Think Tank has no server. It runs on the user's own PC and talks directly to Google's APIs. The Google sign-in token is stored in Windows Credential Manager on that PC. Emails and events are fetched when the app needs them and are not saved to disk. They are held only briefly in memory to show them on screen.

4 · Sharing

Google user data is not shared with anyone, with one exception. When the user clicks to have a reply drafted, the text of that one email thread is sent to Anthropic's Claude, through the Claude Code app signed in to the user's own Claude account, to write the draft. The user reviews the draft, saves it to Gmail, and sends it themselves. Nothing is sent to Claude unless the user asks for a draft.

5 · Google API Services User Data Policy

Think Tank's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6 · Removing access and deleting data

Click Disconnect in the app's Connections panel to delete the stored token, or remove Think Tank at myaccount.google.com/permissions. Because emails and events are not saved, nothing else needs to be deleted.

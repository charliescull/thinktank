Personal desktop dashboard · Windows

One screen for the day.

Think Tank is a private desktop app that Charlie Scullion built for personal use. It puts a calendar, priority email, class deadlines and notes in one window on a Windows PC.

What it does with Google

  • Google Calendar. Shows upcoming events, and creates an event with a Google Meet link when the user fills in the New meeting form and clicks to send it.
  • Gmail. Reads recent inbox threads to sort them by priority, and saves reply drafts to Gmail. It never sends email. The user reviews and sends every draft in Gmail.

Who it is for

Think Tank is not a public product. It is not sold or distributed, and it signs in only the Google account of its owner. All data stays on the owner's computer. See the privacy policy.
